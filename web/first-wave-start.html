五项硬条件 · 全部满足（AND）

t 为查询交易日；价格与均线使用前复权（QFQ）。所有“此前30日”成交量窗口均为 t-30 至 t-1，排除当天；涨幅和量比阈值包含等号，均线排列及收盘大于开盘均为严格大于。

  1. 截至昨日30交易日涨幅10% ≤ close[t-1] / close[t-31] - 1 ≤ 50%端点使用 t-31 与 t-1，不包含当天涨幅。
  2. 当日均线多头MA10 > MA20 > MA30 > MA60均线计算包含当天，不附加均线上升或其他趋势要求。
  3. 当量放大volume[t] ≥ 3 × min(volume[t-30:t-1])当天成交量至少为此前30日最小量的3倍。
  4. 当天涨幅与阳线close[t] / close[t-1] - 1 ≥ 5% 且 close[t] > open[t]当天前复权收盘价相对昨日涨幅至少5%，同时收盘价必须严格大于开盘价，平盘不通过。
  5. 此前量能稳定max(volume[t-30:t-1]) / min(volume[t-30:t-1]) ≤ 3此前30日最大量与最小量之比不超过3。
