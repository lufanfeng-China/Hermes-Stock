# 技术面评估系统 — 重新设计方案 v2

## 设计原则

| 原则 | 说明 |
|------|------|
| **结论驱动** | 输出「建议关注/持有/回避」而非 72.3 分 |
| **一眼看懂** | 红黄绿信号灯 + 一句话结论，零翻译成本 |
| **只说人话** | 「多头排列」而非「MA20>MA50>MA120>MA250 成立」 |
| **极简维度** | 4 个维度，各一个结论词，不堆指标 |

## 四维评估框架

每个维度只看最核心的东西，输出一个**标签 + 颜色 + 一句话证据**：

### 维度一：趋势 📈

| 信号 | 条件 | 含义 |
|------|------|------|
| 🟢 多头排列 | MA20 > MA50 > MA120 > MA250 全部成立 | 趋势健康向上 |
| 🟡 震荡 | 部分均线交叉，无明确方向 | 方向不明 |
| 🔴 空头排列 | 均线全面反序 | 趋势向下 |

### 维度二：动强 🚀

复用现有 RPS 系统，综合近期涨跌：

| 信号 | 条件 | 含义 |
|------|------|------|
| 🟢 强势 | RPS综合>70 或 60日涨幅>同行业均值 | 领先市场 |
| 🟡 中性 | RPS综合 30-70 | 随大流 |
| 🔴 弱势 | RPS综合<30 或 持续跑输 | 落后市场 |

### 维度三：量能 📊

| 信号 | 条件 | 含义 |
|------|------|------|
| 🟢 放量配合 | 近5日量>20日均量120% 且 价格上涨 | 资金认可 |
| 🟡 正常 | 量比 0.7-1.2 | 交易平稳 |
| 🔴 量价背离 | 放量下跌 或 缩量上涨无力 | 资金出逃 |

### 维度四：位置 📍

股价在自身历史中的位置（复用刚做的 5年分位数据）：

| 信号 | 条件 | 含义 |
|------|------|------|
| 🟢 低位 | 5年分位 < 25% | 处于历史低位 |
| 🟡 中位 | 5年分位 25-75% | 中间位置 |
| 🔴 高位 | 5年分位 > 75% | 处于历史高位 |

## 综合结论 = 四个信号灯的逻辑组合

不搞加权分数，直接用决策树：

```
如果 趋势=🟢 且 动量=🟢 且 量能≠🔴
    → 🟢 建议关注  "趋势向好、动量强势、量能配合"

如果 趋势=🟢 且 动量=🟡 且 位置≠🔴
    → 🟡 可观察  "趋势OK但动量不足，等待催化剂"

如果 趋势=🟢 且 位置=🟢
    → 🟡 左侧关注  "趋势在但处于低位，可能筑底"

如果 趋势=🔴 或 动量=🔴
    → 🔴 建议回避  "趋势走弱或动量崩溃"

其他
    → 🟡 观望持有  "信号不明确，等待方向明朗"
```

### 筛选器中的技术面条件

不设百分位输入框，改用**下拉选择**（傻瓜式）：

```
技术面趋势:  [ 不限 | 多头排列 | 非空头 ]
技术面动量:  [ 不限 | 强势 | 非弱势 ]
技术面量能:  [ 不限 | 放量配合 | 非背离 ]
技术面位置:  [ 不限 | 低位 | 非高位 ]
综合建议:    [ 不限 | 建议关注 | 非回避 ]
```

## 与现有系统的关系

```
现有: 财务评分(7维) + 估值分位 + RPS + 5年分位
新增: 技术面信号灯(4维) + 综合建议

筛选器可组合: 
  财务面: ROE≥80分 且 现金流≥70分
+ 技术面: 趋势=多头排列 且 位置=低位
→ 找出「基本面好 + 技术面买点」的股票
```

## 计算性能

4个维度都是轻量计算（MA对齐、RPS读取、量比、分位查表），
全市场 5000 只股票预计 **30-60 秒**完成。
