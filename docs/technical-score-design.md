# 技术面评估系统 - 方案设计

## 1. 数据基础

利用现有通达信本地日线数据（`/mnt/c/new_tdx64/vipdoc/*/lday/*.day`），每只股票提供完整的 OHLCV 时间序列：

| 字段 | 用途 |
|------|------|
| close | 价格趋势、均线、动量、回撤 |
| high/low | ATR、波幅、支撑阻力 |
| volume | 量比、量价关系、OBV |
| amount | 辅助量价分析 |
| RPS20/50/120/250 | 已有全市场截面动量排名 |

已有能力复用：
- RPS 排名系统（全市场 5192 只）
- 均线系统（MA20/50/120/250）
- 日线读取管线（mootdx → pandas）

## 2. 评估框架：5 维度 × 18 子指标

与现有财务评分系统一致：子指标 → 全市场截面百分位(0-100) → 维度加权 → 总分。

### 维度一：趋势质量 (Trend Quality) — 权重 25%

衡量均线排列的健康程度和趋势强度。

| # | 子指标 | 计算方式 | 方向 |
|---|--------|----------|------|
| T1 | MA多头排列得分 | MA20/50/120/250 多头排列天数 ÷ 120天 | ↑ |
| T2 | 价格相对位置 | (close - MA50) ÷ MA50 | ↑ |
| T3 | 长均线斜率 | MA120 近20日变化率 | ↑ |
| T4 | ADX趋势强度 | 14日 ADX 值 | ↑ |

### 维度二：动量强度 (Momentum) — 权重 25%

综合短期和长期价格动量。

| # | 子指标 | 计算方式 | 方向 |
|---|--------|----------|------|
| M1 | RPS 综合 | (RPS20+RPS50+RPS120+RPS250) ÷ 4 | ↑ |
| M2 | 20日涨幅 | close / close_20d_ago - 1 | ↑ |
| M3 | 60日涨幅 | close / close_60d_ago - 1 | ↑ |
| M4 | 新高距离 | close / 250日最高价 | ↑ |

### 维度三：量价配合 (Volume-Price) — 权重 20%

量价关系是技术分析核心。

| # | 子指标 | 计算方式 | 方向 |
|---|--------|----------|------|
| V1 | 量比 | volume / MA(volume, 20) | ↑ |
| V2 | 量价趋势一致 | Corr(volume, close, 20日) 正值表示量价齐升 | ↑ |
| V3 | OBV 趋势 | OBV 20日变化率 | ↑ |
| V4 | 缩量企稳 | volume / MA(volume, 50) — 在0.5-1.2之间为佳 | 适中 |

### 维度四：波动与风险 (Volatility) — 权重 15%

波动率控制对持仓体验和风险控制至关重要。

| # | 子指标 | 计算方式 | 方向 |
|---|--------|----------|------|
| W1 | 波动率倒数 | 1 / (20日年化波动率) | ↑ |
| W2 | 最大回撤倒数 | 1 / (60日最大回撤 + 0.01) | ↑ |
| W3 | Beta可控 | 1 / (|Beta - 1| + 0.3) — 接近1最优 | 适中 |

※ Beta 用个股日收益 vs. 全市场等权日收益的 120 日回归斜率近似

### 维度五：形态信号 (Pattern) — 权重 15%

捕捉短期交易信号。

| # | 子指标 | 计算方式 | 方向 |
|---|--------|----------|------|
| P1 | MACD信号 | MACD 柱状线方向（正值=向上） | ↑ |
| P2 | 突破信号 | (close - 20日最高) / 20日最高，正值=创新高 | ↑ |
| P3 | 回踩均线 | -|close - MA20| / MA20，接近均线为佳 | 适中 |
| P4 | RSI位置 | RSI(14)，30-70 为健康区间 | 适中 |

## 3. 评分计算流程

```
Step 1: 对每只股票，读取近 250 个交易日 OHLCV
Step 2: 计算 18 个子指标的原始值
Step 3: 对每个子指标，在全市场 5192 只股票中计算百分位排名 (0-100)
Step 4: 维度得分 = Σ(子指标百分位 × 子指标权重)
Step 5: 总分 = Σ(维度得分 × 维度权重)
        = Trend×0.25 + Momentum×0.25 + Volume×0.20 + Volatility×0.15 + Pattern×0.15
```

## 5. 前端展示

### 新页面：`/technical-score.html`

- 输入股票代码 → 显示技术面雷达图 + 5维度明细表
- 与财务评分页保持一致的深色终端风格

### 股票筛选器集成

在筛选条件中新增「技术面」分组：
- `min_tech_total_score` — 技术面总分 ≥
- `min_tech_trend` / `min_tech_momentum` / 等 — 各维度 ≥
- 可组合财务面 + 技术面同时筛选

## 6. 实现计划

| 步骤 | 文件 | 说明 |
|------|------|------|
| 1 | `scripts/build_technical_score.py` | 预计算脚本：遍历全市场、算18指标、百分位、保存 JSON |
| 2 | `app/search/index.py` | 新增 `_load_technical_score()` 加载器 |
| 3 | `app/search/index.py` | 筛选器行中加入技术面字段 + 过滤条件 |
| 4 | `web/stock-screener.html` | 新增技术面筛选输入 |
| 5 | `web/technical-score.html` + `.js` | 新增技术面评估独立页面 |

## 7. 预期效果

- 与财务评分互补：财务面看「公司好不好」，技术面看「时机对不对」
- 在筛选器中可以同时设财务+技术条件，比如「ROE≥80分 且 趋势质量≥70」
- 运行时间：全市场 5192 只 × 250 日 ≈ **2-3 分钟**（纯 Python 单进程）
- 可每日盘后自动更新
