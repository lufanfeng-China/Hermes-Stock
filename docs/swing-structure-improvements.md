- 现行对照：两类都要求最近三处已确认峰严格齐降，且当期通达信前复权**收盘价严格超过最近确认峰 C**才成为各自的越峰反转候选；区别在谷的形状：正统下行的最近三谷严格齐降，高点降低型下行形状的最近三谷既非严格齐升也非严格齐降。后者之所以称“形状”，是因为越峰后不再满足原“高点降低型下行”主状态的价格守卫。用户希望两类都在越过 C 以前，用相同的三峰连线形成早期关键价。
- 已实现口径（功能验收不代表收益验证）：只取当日已确认的最近三峰 A、B、C，以它们的**极值发生日对应的有效交易 bar 序号**连接 AB、AC、BC，向当天延长，取三线当日价中的最高者为压力线关键价。不得按图像像素/自然日定位，也不得将尚未确认的峰提前放入历史信号。当日前复权收盘从前一有效K线的线下首次严格越过该关键价、但尚未越 C 时，仅标“下降压力线触发（早期观察）”，记录三峰及其确认日、三条线当日价、关键价、触发日；已越 C 的仍按现有越峰规则，不能把两种证据混称。
- 已验收口径：触发日冻结关键价；其后连续 5 根**有效交易日线**收盘均严格高于冻结价，才标“压力线突破持续5日（仍待结构确认）”；中途收回冻结价及以下则撤销此次持续性候选，等待新的有效触发。这里的 5 根是**信号之后的持续性检查**，与极值发生后 5 根确认峰谷不同；即便达标也不能叫“上行反转已确认”或据此新增强利多星级。
- 关键风险与边界：三条下降线不断向右延伸会越来越低，横盘也可能被动越线。首次触发窗口为C确认后30根有效K线；三线当日最高关键价≤0时直接无效、不得触发（不取零、不钳位、不沿用旧线）。关键价>0时不另加未经验证的相对C峰比例门槛；保留三线与关键价供审计，不能把横盘被动越线说成反转。出现新确认C峰、三峰链改变时，旧线已触发但未满5根的持续观察也立即失效，按新确认C峰重新起算30根，绝不回填旧日期。
