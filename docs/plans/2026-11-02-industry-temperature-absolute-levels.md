# 行业/概念温度改绝对口径（已实施，数据截至 2026-10-30）

> 状态：**已实施并验收**。截至 2026-11-02 收盘后前复权导出仍为 2026-10-30，当前快照截止日明确为 2026-10-30。
> 记录日期：2026-11-02
> 触发原因：现有档位是截面分位，导致「跌 9% 的行业被标成升温」。

## 一、问题证据（2026-10-30 快照，10 日窗口）

```
档位 ≥3（升温/热门/极热）的行业：52 个
其中「中位涨幅 ≤ 0」的：45 个（87%）
全市场 128 个行业中位涨幅 > 0 的：只有 7 个
```

极端案例：

| 行业 | 旧档位 | 中位涨幅 | 广度 | 超额 |
|---|---|---:|---:|---:|
| 产业互联网 | 3 升温 | −9.23% | 33.3% | −1.52% |
| 专用设备 | 3 升温 | −8.04% | 20.9% | −0.33% |
| 食品加工 | 3 升温 | −8.02% | 24.3% | −0.30% |
| 物流 | 3 升温 | −7.05% | 14.6% | +0.66% |

根因（`app/concept_temperature.py:121-134`）：

```python
冰点(0):  score_percentile ≤ .20 且 median_return ≤ 0 且 breadth < 35
偏冷(1):  score_percentile ≤ .40        ← 纯排名
中性(2):  score_percentile ≤ .60        ← 纯排名
升温(3):  score_percentile ≤ .80 或 median_return ≤ 0 或 breadth < 55 或 excess ≤ 0
极热(5):  score_percentile ≥ .95 且 6 个绝对条件
热门(4):  其余
```

`score_percentile` 是当天 128 个行业的排名分位，`heat_score` 本身也是
5 个指标的加权分位（30/25/20/15/10），所以**档位与 heat_score 都不含绝对含义**：
每天恒定约 25 个行业落在偏冷、25 个落在中性。

## 二、目标口径

档位由**行业中位涨幅（绝对）**决定，排名只作辅助展示。

### 2.1 档位阈值（单位：行业中位涨幅 %）

| 窗口 | 冰点 | 偏冷 | 中性偏弱 | 升温 | 热门 | 极热 |
|---|---:|---:|---:|---:|---:|---:|
| 3 日 | ≤ −5 | −5 ~ −2 | −2 ~ 0 | 0 ~ +1.5 | +1.5 ~ +3 | ≥ +3 |
| 5 日 | ≤ −7 | −7 ~ −3 | −3 ~ 0 | 0 ~ +2 | +2 ~ +4.5 | ≥ +4.5 |
| 10 日 | ≤ −12 | −12 ~ −5 | −5 ~ 0 | 0 ~ +3 | +3 ~ +6 | ≥ +6 |
| 20 日 | ≤ −18 | −18 ~ −7 | −7 ~ 0 | 0 ~ +4.5 | +4.5 ~ +9 | ≥ +9 |
| 60 日 | ≤ −30 | −30 ~ −10 | −10 ~ 0 | 0 ~ +8 | +8 ~ +15 | ≥ +15 |

### 2.2 附加门槛（防止少数股票拉动）

```
升温：广度 breadth_pct ≥ 50
热门：广度 ≥ 60  且  超额 excess_return_pct > 0
极热：广度 ≥ 75  且  超额 > 0  且  强势股占比 strong_stock_pct ≥ 30
特殊：中位涨幅 > 0 但广度 < 50 → 标签「分化上涨」，档位归 2（中性偏弱）
```

### 2.3 保留辅助列（用户确认保留）

以下字段继续输出，但**不参与档位判定**：

- `heat_score`（0–100，5 指标加权分位）
- `heat_rank`（行业间排名，1 = 最热）
- `heat_percentile`（排名分位，0–1）

前端表格需同时展示「绝对档位」与「相对排名」，并在 tooltip 中说明二者区别。

## 六、验收标准

1. 用 2026-10-30 快照重算，10 日窗口档位分布必须等于上表（6/1/0 升温/热门/极热）
2. 中位涨幅 ≤ 0 的行业，档位必须 ≤ 2（不允许出现「升温」）
3. 广度 < 50 且中位涨幅 > 0 的行业，标签必须是「分化上涨」且档位 = 2
4. `heat_score` / `heat_rank` 数值与改动前完全一致（不参与判定，不得被波及）
5. 前端能同时显示绝对档位与相对排名，tooltip 说明差异
6. 全仓测试通过

## 七、风险与未决

- **档位数量每天变化**：不再恒定 25 个/档，用户原有的读表习惯需调整
- **升温/退坡频率下降**：绝对档位跳变少于排名跳变，`temperature_streak_days` 分布会变
- **阈值未经历史检验**：+3%/+6%（10 日）是按当日数据定的，未来若做策略回测需做敏感性分析
- **快照生成耗时**：档位不受影响，但 60 日历史重建会增加一次构建开销
