## 已实施

1. 扣非利润CAGR不适用时，使用利润路径评分：扭亏、亏损收窄、亏损扩大、持续亏损、亏损/盈亏平衡转换、盈利转亏。
2. `profit_to_loss`按利润路径0/13分处理，但维度有效，归入`deteriorating_track`。
3. 五年累计扣非利润≤0时，现金质量使用绝对现金创造：累计经营现金流、正现金流年度数、最新经营现金流率、OCF趋势，并保留FCF率子项。
4. 原始字段缺失保持`unavailable`；金融地产等保持`not_applicable`。
5. 新增`five_year_standard`、`recovery_track`、`deteriorating_track`口径；恢复/恶化分不进入标准优质池，也不与季度分混成标准五年综合分。
6. 修复财务仓代码因证券主表缺失而被严格快照跳过的问题；按代码前缀推导sh/sz/bj。
7. 修复北交所行业表市场值`2`在动态单股API中未归一化为`bj`的问题。
8. 股票筛选、股票分析、概念成分股显示“恢复型/恶化型/不适用”标签并披露增长、现金评分依据。
