# 五年健康恢复型评分改造规格 v1

- 冻结日期：2026-11-23
- 状态：**仅保存方案，尚未实施、未重建快照、未改变生产评分**
- 适用对象：通用工商企业五年健康评分中，因亏损/扭亏导致扣非利润 CAGR 不适用，或五年累计扣非利润≤0导致现金利润比不适用的公司。
- 不适用对象：原始字段缺失、年报不连续、银行/证券/保险/房地产等专用行业。

## 1. 目标

1. 数学上不适用时采用可审计替代评分，不因 CAGR/比率不可算就整维度空缺。
2. 真正缺数据时继续空值，禁止把缺证据当成0分或通过。
3. 恢复型分数与标准连续盈利分数分轨展示，不直接混入普通优质公司池。
4. 保留现有六维权重与综合分覆盖率闸门：覆盖率≥85%，财务风险维度必须有效。

## 2. 增长质量替代：利润路径评分

增长质量仍为20分：

- 营收CAGR：最高7分，沿用现有标准；若营收字段缺失，则增长维度继续不可用。
- 利润部分：最高13分。标准盈利公司沿用“扣非利润CAGR 7分＋利润增长溢价6分”；CAGR不适用时改用利润路径。

### 2.1 利润路径基础分

| 路径 | 基础分（13分部分） |
|---|---:|
| 标准盈利且CAGR有效 | 沿用原7＋6算法 |
| turnaround：扭亏 | 6 |
| loss_to_break_even：亏损转盈亏平衡 | 4 |
| loss_narrowing：亏损收窄 | 3 |
| loss_flat：持续亏损持平 | 1 |
| loss_widening：亏损扩大 | 0 |
| break_even_to_loss：盈亏平衡转亏损 | 0 |
| unknown：字段缺失或无法判断 | 不可用，不评分 |

### 2.2 持续性加分

在路径基础分上加分，利润部分总分封顶13分：

- 最近连续2个完整年度扣非利润>0：+3；
- 最近连续3个完整年度扣非利润>0：再+2；
- 最近4段年度变化中至少3段改善：+2。

亏损收窄公司因不能获得连续盈利加分，通常最高5分；刚扭亏不会直接获得满分。

## 3. 现金质量替代：绝对现金创造评分

现金质量仍为20分：

### 3.1 标准路径

五年累计扣非利润>0且现金利润比有效时：

- 五年现金利润比：最高10分，沿用现有算法；
- 最新自由现金流率：最高10分，沿用现有算法。

### 3.2 恢复路径

五年累计扣非利润≤0时，现金利润比标记为“不适用”，用绝对现金创造能力替代其10分：

1. 五年累计经营现金流>0：2分，否则0分；
2. 五年经营现金流为正年度数：5年=3分，4年=2分，3年=1分，少于3年=0分；
3. 最新年度经营现金流率（经营现金流/营收）：≥10%=3分，≥5%=2分，>0=1分，≤0=0分；
4. 五年经营现金流趋势：上升=2分，平稳=1分，下降=0分。

自由现金流率仍按现有10分规则评分。若经营现金流、营收或自由现金流的必要年度字段缺失，现金质量仍不可用。

## 4. 口径与状态字段

恢复型评分必须返回：

```json
{
  "assessment_track": "recovery_track",
  "growth_quality_basis": "profit_path",
  "cash_quality_basis": "absolute_cash_support",
  "profit_path": "turnaround",
  "score_comparable": false
}
```

标准公司：

```json
{
  "assessment_track": "five_year_standard",
  "growth_quality_basis": "cagr",
  "cash_quality_basis": "cash_profit_ratio",
  "score_comparable": true
}
```

## 5. 质量池隔离

### 标准优质

- five_year_standard；
- 五年健康≥70；
- 覆盖率≥85%；
- 无高/极高年度红旗。

### 恢复型候选

- recovery_track；
- 最新年度扣非利润已转正；
- 优先要求连续2个完整年度盈利；
- 当季扣非利润为正；
- TTM自由现金流率≥0；
- 无高/极高红旗。

### 仍在亏损

可以有综合分，但只能标记“亏损改善观察”，禁止标记“标准优质”。

## 6. 明确禁止

- 不把缺失字段统一记0分；
- 不降低85%覆盖率门槛来制造分数；
- 不对负利润取绝对值计算CAGR；
- 不给利润分母加epsilon；
- 不用季度数据填补五年年报维度；
- 不把恢复型分数与标准盈利分数无标识混排。

## 7. 实施验收边界

正式实施必须先TDD，至少覆盖：

1. 标准盈利路径结果完全不变；
2. 扭亏、连续两年盈利、连续三年盈利的递进分数；
3. 亏损收窄、持平、扩大、转亏的顺序与上限；
4. unknown字段缺失仍为空；
5. 累计扣非利润≤0且绝对现金证据完整时可评分；
6. 经营现金流/营收/FCF缺失时仍为空；
7. 覆盖率、财务风险闸门保持；
8. API/UI明确显示恢复型口径；
9. 恢复型候选不自动进入标准优质池；
10. 重建全市场快照后输出恢复数量、仍为空数量及原因对账。

## 8. 当前估算（非实施结果）

基于2026-11-19现有派生字段，理论上最多约831只可能恢复出分；实际数量取决于五年经营现金流与营收序列完整性。该数字是上限估算，不是已重建结果。
