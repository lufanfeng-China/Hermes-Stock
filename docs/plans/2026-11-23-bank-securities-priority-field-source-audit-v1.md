# 银行与证券第一优先级缺失字段来源核验 v1

- 核验日期：2026-11-23
- 范围：银行42只、证券48只
- 状态：只做来源核验；未启动全市场下载、字段提取、评分开发

## 一、结论

第一优先级字段可以获取。最佳主来源是巨潮资讯/交易所发布的上市公司年度报告原始PDF，而不是非官方行情接口。

通达信统一财务仓缺少这些字段，不代表上市公司没有披露。代表性真实年报核验表明：

- 招商银行2024年报包含不良贷款率、拨备覆盖率、核心一级资本充足率、一级资本充足率、资本充足率、净利差/净利息收益率、成本收入比、流动性覆盖率、净稳定资金比例。
- 宁波银行2024年报包含不良贷款率、拨备覆盖率、核心一级资本充足率、一级资本充足率、资本充足率、净息差/净利息收益率、成本收入比、流动性覆盖率。
- 中信证券2024年报包含净资本、风险覆盖率、资本杠杆率、流动性覆盖率、净稳定资金率、经纪业务、投资银行业务、资产管理业务、融出资金。
- 广发证券2024年报包含同类监管指标和业务字段。

## 二、已验证的公开获取链路

### 1. 巨潮资讯历史公告查询

接口：

```text
POST https://www.cninfo.com.cn/new/hisAnnouncement/query
```

返回：证券代码、名称、机构ID、公告ID、公告时间、标题和PDF相对路径。

原始PDF：

```text
https://static.cninfo.com.cn/{adjunctUrl}
```

已验证PDF为`application/pdf`，可用PyMuPDF读取文本和表格上下文。

代表性原始PDF：

```text
招商银行2024年报
https://static.cninfo.com.cn/finalpage/2025-03-26/1222895154.PDF

中信证券2024年报
https://static.cninfo.com.cn/finalpage/2025-03-27/1222912838.PDF

宁波银行2024年报
https://static.cninfo.com.cn/finalpage/2025-04-10/1223045151.PDF

广发证券2024年报
https://static.cninfo.com.cn/finalpage/2025-03-29/1222949775.PDF
```

四只样本均可一次查询出2019—2024六份完整年报，足以支持五年历史提取。

### 最新完整年报不是2024A，而是2025A

截至2026-11-23，巨潮已经可以查询并下载：

```text
招商银行2025年度报告：2026-03-28披露
中信证券2025年度报告：2026-03-27披露
宁波银行2025年度报告：2026-04-25披露
广发证券2025年度报告：2026-03-31披露
```

已进一步下载并解析招商银行、中信证券2025年度报告：

- 招商银行2025年报仍包含不良贷款率、拨备覆盖率、核心一级资本充足率、资本充足率、净利息收益率和成本收入比；
- 中信证券2025年报仍包含净资本、风险覆盖率、资本杠杆率、流动性覆盖率、净稳定资金率、经纪/投行/资管业务和融出资金。

因此当前五年年度窗口应使用`2021A—2025A`。2026A尚未结束并披露，正常要到2027年年报季才能纳入。2026年的最新经营监测可另用2026Q3，但季度报告不保证完整披露所有年度监管指标，不能替代完整年报评分。

### 2. 上交所公告接口

已验证：

```text
GET https://query.sse.com.cn/security/stock/queryCompanyBulletin.do
```

可按股票代码和年度报告类型返回标题及上交所PDF路径。招商银行返回2023—2025年度报告记录。

当前运行环境直接下载上交所PDF会遇到浏览器挑战，因此建议：

- 巨潮PDF作为批量主链路；
- 上交所/深交所公告元数据作为公告日期和文件一致性交叉验证；
- 不依赖单一站点静态URL。

### 3. 公司投资者关系网站

适合作为补充来源，尤其是：

- 银行资本充足率信息披露报告、第三支柱报告；
- 券商风险控制指标报告；
- 年报英文版或更清晰的专项表格。

不足：各公司URL、页面结构和历史归档方式不统一，不适合作为第一批量入口。

### 4. 监管机构网站

金融监管总局、证监会适合获取：

- 监管口径和最低标准；
- 行业汇总数据；
- 规则变更和指标定义。

不宜作为90只公司五年逐公司明细的主要数据源，因为公开统计通常偏行业汇总，逐公司历史字段不如年报集中。

### 5. 商业数据库

Wind、Choice、iFinD、CSMAR/CNRDS可能提供标准化字段及API/导出，但需要：

- 合法账号和数据授权；
- 单独核验42只银行、48只证券的五年覆盖；
- 核验字段口径、合并范围和历史修订；
- 保留原始年报链接作为审计证据。

若已有授权，商业库适合做提取加速和交叉校验，但不应成为无法追溯原报告的唯一证据。

## 六、关键口径风险

1. 银行净息差可能写成“净利息收益率”，必须维护别名，不能只搜一个词。
2. 银行指标可能同时披露“集团”和“本行”；评分前必须固定使用集团/合并口径。
3. 券商净资本和风险控制指标通常是母公司监管口径，财务报表利润可能是合并口径；必须保留`scope`，不能假装完全同口径。
4. 净息差、成本收入比可能是期间指标；资本充足率、不良率通常是期末指标，时间基准要分开。
5. 年报可能同时给本期和上期值。五年数据库应保留报告版本和公告日期，不能只抄最新报告中的回溯列而丢失修订轨迹。
6. PDF表格存在跨页、合并单元格、百分号和单位变化；不能仅靠正则匹配数字，必须做表格级校验。
7. 访问巨潮和交易所应限速、本地缓存、避免重复下载，并遵守网站使用条款。

## 七、建议优先级

### 第一阶段：只用年报原文补核心字段

银行先补7项：

```text
不良贷款率
拨备覆盖率
核心一级资本充足率
一级资本充足率
资本充足率
净息差/净利息收益率
成本收入比
```

证券先补8组：

```text
净资本
风险覆盖率
资本杠杆率
流动性覆盖率
净稳定资金率
经纪/投行/资管收入拆分
融出资金
```

### 第二阶段

- 银行增加关注类贷款率、贷款拨备率、流动性监管指标；
- 券商增加自营风险限额、各项风险资本准备、信用业务细分；
- 公司官网专项报告作为补充和交叉验证。

### 当前建议

优先采用“巨潮年报PDF＋交易所公告元数据”双源链路。它公开、五年历史可得、可批量、能追溯到原始报告，当前已验证代表性银行和券商样本。商业数据库可作为可选加速层，但不应替代原始年报证据。
