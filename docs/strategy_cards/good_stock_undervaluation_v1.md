# 好股 + 低估诊断规则账本（v1）

状态：规则逐项冻结中。未写为“已确认”的内容不得进入实现、快照或页面逻辑。

## 产品边界（已确认）

- 先判断企业是否具备“好股”质量，再对合格企业展示估值安全边际与经营动量四象限。
- 质量不合格、或证据不足的公司不得进入四象限；必须保留失败/缺失原因。
- 五个完整年度的质量结论与最新季度监测必须分层展示；季度信息不得覆盖年度结论。
- 估值指标、模型适用性、报告期、公式和缺失原因均需可审计。

## D1：质量准入架构（已确认）

采用**混合式**质量门：

1. 五个完整年度的综合健康度为质量准入证据；
2. 独立的重大财务红旗为硬否决项；
3. 最新季度仅形成风险标签，不覆盖五年年度结论。

## D2：年度综合健康度准入线（已确认）

- 五个完整年度综合健康度：`>= 70`；
- 年度证据覆盖率：`>= 85%`；
- 覆盖不足时状态为 `INSUFFICIENT_EVIDENCE`，不得视为通过；
- 达到分数和覆盖率后，仍须通过后续独立红旗否决。

## D3：年度财务红旗否决（已确认）

- 在已评估的五年年度红旗中，任一项为 `高严重度` 或 `极高风险`，即为 `NOT_QUALITY_ELIGIBLE`；
- `普通关注` 仅作为可见风险标签，不单独否决；
- 不可评估、不可适用、或覆盖不足必须显式返回原因，不能转化为未触发红旗；
- 每项红旗的量化升级阈值、比较期与严重度依据仍须逐项审计并冻结。

## D4：首版行业覆盖（已确认）

- 首版仅对**非金融、非房地产**普通 A 股进行“好股 + 低估”诊断；
- 银行、券商、保险及其他金融企业，以及房地产企业，不使用通用质量门；
- 这些行业返回 `NOT_APPLICABLE` / `行业专用规则未就绪`，不得显示为质量不合格，也不得进入四象限；
- 未来纳入前，必须分别冻结金融的 PB–ROE / 资本安全规则，以及地产的 NAV、资产负债与现金流规则。

## D5：HAS_MARGIN 估值证据架构（已确认）

- 仅已通过质量门的非金融、非地产公司可判定 `HAS_MARGIN`；
- 必须同时存在并通过两项独立证据：行业相对估值折价、以及自身历史估值折价；
- 保守内在价值模型若适用，作为增强证据；模型不可用不得自动导致质量失败或估值通过；
- 不得把行业整体低迷、负 TTM 盈利或模型不可用伪装成估值安全边际；
- 行业相对折价与自身历史折价的具体阈值仍待逐项确认。

## D6：行业相对估值折价（已确认）

- 使用所属二级行业内的有效样本，且 `PE-TTM` 与 `PS-TTM` **均**位于低估 30% 区间，才通过行业相对折价；
- 负 TTM 盈利、PS 缺失、行业映射缺失或行业有效样本不足时，行业相对估值为 `UNAVAILABLE`，不得通过；
- PE/PS 的报告期、TTM 公式、行业有效样本数、百分位口径均须随结果保留。

## D7：自身历史估值折价（已确认）

- 要求 `PE-TTM` 与 `PS-TTM` 均位于该公司有效、可比历史观测的低估 30% 区间；
- `PB` 仅作审计展示，不作为首版 `HAS_MARGIN` 的硬条件；
- 负 TTM 盈利、PS 缺失或历史序列不足时，自身历史估值为 `UNAVAILABLE`，不得通过；
- 历史覆盖期、有效观测数、百分位口径和剔除原因必须可审计。

## D8：自身历史估值的最低覆盖（已确认）

- 用于自身历史 PE/PS 百分位的可比数据须覆盖最近至少 3 个自然年；
- `PE-TTM` 与 `PS-TTM` 各自至少 500 个有效交易日观测；
- 未达任一条件即为 `INSUFFICIENT_EVIDENCE`，不进入 `HAS_MARGIN`；
- 结果须显示实际覆盖起止日、两项有效观测数与不足原因。

## D9：经营动量（已确认）

- 四象限纵轴 `IMPROVING` 同时要求最新累计季报的营收同比为正、扣非归母净利润同比为正，且季度盈利状态为 `稳定` 或 `改善`；
- 任一条件不满足，归为 `STABLE_OR_MILDLY_WEAKENING`；
- 季度高风险或极高风险保留为可见警示标签，不覆盖年度质量准入，也不改变已确认的年度红旗否决逻辑；
- 返回并展示营收同比、扣非归母净利润同比、季度盈利状态、报告期、数据可用性及季度风险证据。

## D10：保守内在价值模型（已确认）

- 首版内在价值模型不是 `HAS_MARGIN` 的必要条件；
- 若项目中已有可审计、行业适用的保守模型结果，可作为增强证据展示；
- 未构建、不可适用或证据不足时必须明确写明原因，不得生成推测性 DCF 或把它转为通过/失败；
- 后续若扩展模型，须独立冻结模型适用条件、输入假设、保守情景与审计字段。

## D11：年度红旗的缺失证据（已确认）

- 年度综合评分与覆盖率达到准入线后，仍可评估质量门；
- 但现金流质量、杠杆/偿债安全、盈利持续性三类**核心红旗**中，任一整类不可评估，即为 `INSUFFICIENT_EVIDENCE`，不得进入“好股”池；
- 非核心红旗不可评估时必须披露原因，但不单独阻止准入；
- 实现时必须把每条红旗映射到明确的证据类别，不得以空值或未触发替代不可评估。

## D12：快照与历史 PIT（已确认）

- 首版同时提供当前快照与指定历史日的 PIT 快照；
- 历史快照仅可使用 T 日已公告财报、当日可见行业估值证据及 T 日原始价格；
- 历史数据资产由离线/异步构建产生，带锁、进度、版本和原子写入；
- 禁止用当前财报、当前估值或当前行业数据回填到历史日。

## 待逐项确认（不得默认）

1. 哪些年度红旗构成硬否决，以及各自的定量阈值和持续期；
2. 季度监测哪些严重度仅作标签、哪些应阻止进入“好股”池；
3. 金融、地产、周期、非金融公司的行业适配准入差异；
4. 估值安全边际、经营动量、四象限的定义与边界；
5. 当前与历史 PIT 快照的报告可见性、行业估值和价格口径。
