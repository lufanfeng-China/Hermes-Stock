## 五类综合结论

| 结论 | 颜色 | 逻辑 | 建议操作 |
|------|------|------|----------|
| **建议关注** | 🟢 | 趋势+动量+量能三个全好 | 可以找买点入场 |
| **左侧关注** | 🟡 | 位置低位 + 趋势OK + 量能启动 | 加自选观察，等趋势确认 |
| **可观察** | 🟡 | 趋势OK但动量不足，位置安全 | 等待催化剂 |
| **观望持有** | 🟡 | 趋势动量好但位置/量能有隐患 | 持有不动，不加仓 |
| **建议回避** | 🔴 | 趋势或动量走弱 | 不碰，或减仓 |

注：没有纯🟢的"强烈买入"——技术面永远只是参考，不替代基本面判断。

## 四个维度的判定规则

### 趋势 📈
```
多头排列:  MA20 > MA50 且 MA50 > MA120 且 MA120 > MA250  → 🟢
偏多:      至少2条满足 且 close > MA50                     → 🟢 (宽松版)
震荡:      MA20和MA120在5%内缠绕                           → 🟡
空头排列:  MA20 < MA50 < MA120 < MA250                     → 🔴
偏空:      至少2条反序                                     → 🔴
```

### 动强 🚀 （复用现有 RPS 系统）
```
强势:  RPS120 ≥ 70  或  RPS20 ≥ 80                  → 🟢
偏强:  RPS120 ≥ 55                                   → 🟢
中性:  RPS120 30-55                                  → 🟡
偏弱:  RPS120 < 30                                   → 🔴
弱势:  RPS120 < 20  或  60日涨幅 < -15%              → 🔴
```

### 量能 📊
```
放量配合:  价格5日涨 且 量比>1.2                       → 🟢
正常:      量比 0.7-1.2                                → 🟡
缩量:      量比 < 0.7                                   → 🟡 (中性偏冷)
量价背离:  放量下跌(量比>1.2 且 价格跌) 或             → 🔴
           缩量上涨(量比<0.5 且 价格涨)
```

### 位置 📍 （复用 5年分位）
```
低位:  5年分位 ≤ 25%                                   → 🟢
中位:  5年分位 25-75%                                  → 🟡
高位:  5年分位 > 75%                                   → 🔴
```

## 综合结论决策树

```
if 趋势=🔴 或 动强=🔴:
    → 🔴 建议回避

elif 趋势=🟢 且 动强=🟢 且 量能=🟢 且 位置≠🔴:
    → 🟢 建议关注

elif 趋势=🟢 且 位置=🟢 且 量能≠🔴:
    → 🟡 左侧关注

elif 趋势=🟢 且 动强=🟡:
    → 🟡 可观察

elif 趋势=🟢 且 动强=🟢 且 (位置=🔴 或 量能=🔴):
    → 🟡 观望持有

else:
    → 🟡 观望持有
```

## 筛选器中可用的下拉条件

```
技术面趋势:    [ 不限 | 🟢多头排列 | 🟢非空头 ]
技术面动量:    [ 不限 | 🟢强势 | 🟢非弱势 ]
技术面量能:    [ 不限 | 🟢放量配合 | 🟢非背离 ]
技术面位置:    [ 不限 | 🟢低位 | 🟢非高位 ]
综合建议:      [ 不限 | 🟢建议关注 | 🟢非回避 ]
```

组合示例：
- 「趋势=非空头 + 位置=低位 + 财务ROE≥70」→ 基本面好且在低位的股票
- 「综合建议=建议关注 + 估值分位≤30」→ 技术面好且不贵
